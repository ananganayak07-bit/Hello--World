# Hello--World
This is for practicing GitHub flow.

when you create a repo, by default a branch is created. its called Main branch. 

You can create a new branch by clicking on the new branch icon.

it will create a MD file which is the copy of the main branch. 

after doing all changes, we can save the changes. its called commit. 

these changes will be made only to the newly creted branch that you have created(in the new MD file)  by clicking on COMMIT Changes .
